# Як запустити лабораторну №7

Це **самостійний проєкт**. Попередні архіви не потрібні.

1. Розпакуйте `findex_lab07_only.zip` та відкрийте папку у VS Code.
2. Відкрийте термінал у цій папці.
3. Виконайте команди:

```bash
python -m pip install -e . pytest httpx
python -m findex.cli index data/demo --out data/demo.json
python -m findex.cli serve --port 8000
```

4. Відкрийте http://127.0.0.1:8000 — сторінка пошуку.
5. Відкрийте http://127.0.0.1:8000/docs — документація API.
6. Для перевірки тестів зупиніть сервер через `Ctrl+C` і виконайте:

```bash
python -m pytest -q
python scripts/benchmark_lab07.py
```

Зверніть увагу: результат лабораторної №7 працює **локально**, але публічне посилання ще не створено. Інструкція для Docker/Render і чесно позначені невиконані пункти є в `README.md`.
